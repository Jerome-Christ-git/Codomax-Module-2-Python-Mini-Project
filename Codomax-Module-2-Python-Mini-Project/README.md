# 🎓 Student Management System Pro

## 📌 Project Overview

Student Management System Pro is a Python-based console application developed as part of the **Codomax Digital Solutions Internship - Module 2 (Python Mini Project)**.

The application allows users to manage student records efficiently using a menu-driven interface. It stores student information in a JSON file, enabling permanent data storage even after the program is closed.

---

## 🚀 Features

- ➕ Add Student
- 📋 View All Students
- 🔍 Search Student
- ✏️ Update Student
- 🗑️ Delete Student
- 📊 Student Statistics Dashboard
- 💾 Automatic JSON Data Storage
- 🎯 Automatic Grade Calculation
- ✅ Pass/Fail Evaluation

---

## 🛠️ Technologies Used

- Python 3
- JSON
- File Handling
- Functions
- Lists & Dictionaries
